# LinguaLand — CRM обзвона

Одностраничный сайт для менеджера по продажам. База клиентов внутри `index.html` зашифрована паролем, без пароля видно только окно входа.

## Как обновить сайт

Заменить файл `index.html` новой версией (кнопка Add file → Upload files в GitHub). Сайт пересоберётся сам через минуту.

## Файлы

- `index.html` — вся CRM (воронка, обзвон списком, задачи) и зашифрованная база
- `_headers` — запрет индексации в поиске (для Cloudflare Pages)

Пароль в репозитории не хранится.
